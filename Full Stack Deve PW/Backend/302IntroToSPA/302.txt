     1. Introduction to SPA (302):
  
      -Normally websites par jab visit karte hai, brawser par toh hum ye notice kar sakte hai ki pages refresh nahi ho 
       rahe hai, some parts of the website stick.like linkdin, bookmyshow, etc we on brawser like that ki hum app use

      -App jaise intergration ab website par bhi kar sakte hai, hum collage ki websites dekh sakte hai jaha pages reload hote
       hai. 
      -Single Page Aplication(SPA):- 
        -aise apllication hoti hai jo user se dynamically content rewrite karwane mai help karti hai. matlab user interact
         karega aur dynamically jitna part reload hona chahiye utna reload hoga, ye app like feeling deta hai. 
         - features:- 
            -single page application ka source code hota wo kaffi minimized hota hai.
            - isme hum single page render karte hai aur us single page ko, javascript ki help se modify karte rahte hai.

    Few pointers on jsx(308):

        - user defined component should be start with capital letters. 
        - jsx mai return : humesha single element/entity he return karenge, uske ander multiple elment ho sakte hai.
        - ab hum nahi chahte hai ek extra element add kare, tab hum fragement use kar sakte hai. 
        - fragement : ek ya ek sa jyada elements ko group karne ki functionalality deta hai. but wo apne taraf se extra
          element nahi dalta. ex div in App.js help to group but extra element aa ja raha hai. 
        - fragement use karne se dom par koi extra element add nahi hoga. 
        - final output mai feel hoga ki grouping ki he nahi hai thi. 
        - fragement use karne ke empty open and empty close tag de sakte hai

        jsx based component banate waqat :
         - har component ko kuchh data input kar sakte hai from its parent. is kahte hai props. 
         - component props :- child element ko value bhejna ko he props kahte hai. 
           - html mai extra property add karne ke liye hum attributes use karte the, aur ye bhi html like structure hai. 
           - attributes jaisa he syntex hota hai props ka. 
           - props ex < img src = "...">
             - jab function isko access kar raha hoga tab hum uske parameter mai props.attribute pass ho jate hai.  
             - src ek string expect kar raha tha props.src nahi. lekin ye ek valid javascript expression hai. 
             - isko compute karne ke liye {} mai bind kar sakte hai. 
             - jitne aise attributes honge jo props ka kaam karne wale hai, wo camel case mai rehega hamesha. 
               like class ko className in jsx. 
    
    JSX Curlies:
      - Destructuring the props example
         function Image1(props){
          return (
           <div>
              <img src = {props.src}></img>
              <h2> Hello I  </h2>
            </div>
          )   
        }

      destructure form:
        function Image1({src}){
          return (
            <div>
              <img src = {src}></img>
              <h2> Hello I  </h2>
            </div>
          )   
        }
    
     - allocating default value to the props
        function Image1({src = " Hello I am default value."}){}
