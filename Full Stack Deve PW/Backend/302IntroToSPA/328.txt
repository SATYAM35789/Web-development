What is css framework ? 
- it is important , kyuki core css kisi ko likhna pasand nahi hai.  Ye easy to use hoti hai. Jayda tar framework ke ander prewritten
  css hoti hai. humk sirf class wagera deni hoti hai.
Why CSS framework over CSS.
- Agar hum css likh sakte hai toh kisi aur kikhi hua css kyu use kare, 
  - kyuki consistency rahti hai color, height, font, etc mai. 
  - responsive design easy hoti hai. 
Tailwind CSS?
- Utility First css framework hai jaha par, kaffi kuchh hai , waha se hum easily development kar sakte hai. 

Advantages of Tailwind Css
- Faster and easy development.
- maintainance easy kyuki css collpse nahi karti aapas mai
- responsive design and customizable bhi hota hai means value ko hum change bhi kar sakte hai, ye bahi hai jo uthakar
  laye hai, wahi use karna hai.

Disadvantages of Tailwind Css
- classes ka overview hota, means reuse kaffi jagah karte hai. 
- brawser support deta hai par accessibilty mai issue hota hai
- maintainance developer ke hath mainnahi hai, humko core css ka use karna padta hai.
