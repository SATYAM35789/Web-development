   -// Action objects -> action methods (action creators like addTodo, deleteTodo)
    const addTodo = (todoText) => ({type : ADD_TODO , payload : {todoText}})
    dispatch(addTodo('actionBind'))

    const deleteTodo = (id) => ({type : DEL_TODO, payload: {todoId: id}})

   - ab problem ye hai ki bar-bar hamko dispatch ke ander method call karna pad raha hai, Manlo hamre app Redux ki app hai

    2. jo method as object bheje hai wo bind go jaye, agar by default call kar raha hu to dispatch ke ander call ho raha ho.
   - use karna ka fayda ye hai ki humko pura dispatch pass karne ki zarurat nahi hai hum bas actions.AddTodo bhi de sakte hai, if needed to pass. 

   in documentation:-
   -Turns an object whose value are action creator, into an object with same keys but with every action creator wrapped into
    dispatch calls so they may invoked directly. 
    - means ye ek object leta hai action creator ka aur return bhi karta hai ek object actions creator ka 
    lakin ye returned thode modified hai, ye sare ke sare (addTodo , deleteTodo) dispatch ke ander wrapped hai. Is se hamko dispatch ke
