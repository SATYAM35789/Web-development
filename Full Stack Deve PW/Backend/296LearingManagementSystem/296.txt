 jo kitchen mai unko kuchh integredent ki zarurat padegi. Toh wo Storage mai jayenge aur resove karenge aur chize

Server side:- 
 -External server: Creating external server jo Forgot Password ke case mai email par link bhejega. 
 -Payment Gateways : payment se related kaam karenge. 
 
 API:- Create Api jo ki sare module ke crossponding kuchh n kuchh kaam karngi. 
 1. User level :-
  1. (/api/v1/user) :- User module se related sare api
   - (/register) : Create account
   - (/login) : Login
   - (/changepassword) : Forgot password
   - (/me)  : View Profile
   - (/update)  :- Edit Profile
   - (/logout) : logout

  2. (/api/v1/courses) :- Course se related, sari details  
    - (/) :- View Courses
    - (/:id):- View courses details
